# Third-Party Notices

SATOSHI//REDLINE may distribute third-party software under licenses different from the licenses applied to original project code and documentation.

No third-party components have been recorded in this bootstrap file yet.

When dependencies or bundled assets are added, record each item using this structure:

## Component name

- **Version:** `VERSION`
- **Purpose:** Brief description
- **Source:** Upstream project or package location
- **License:** SPDX license identifier
- **Copyright:** Upstream copyright notice
- **Bundled or linked:** Describe how it is included
- **Required notices:** Reproduce any notice text required by the upstream license

The full text of every license used by files owned by this repository belongs in `LICENSES/`. License texts and notices required solely for third-party dependencies may instead be collected through the project’s dependency-notice generation process, provided distributed artifacts contain all required notices.

Generated third-party notices must not replace review of dependency license compatibility.
